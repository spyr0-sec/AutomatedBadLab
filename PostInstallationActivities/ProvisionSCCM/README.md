# Provision SCCM
This needs to be executed as a PostInstallationActivity once the Configuration Manager site is installed.

## Defining the role
``` PowerShell
$CM1PostInstallJobs = @() # Will execute in order
$CM1PostInstallJobs += Get-LabPostInstallationActivity -CustomRole AutomatedLabSCCM -Properties @{
    SiteCode = $CMSiteCode
}
$CM1PostInstallJobs += Get-LabPostInstallationActivity -CustomRole ProvisionSCCM -Properties @{
    SiteCode     = $CMSiteCode
    UserCount    = $ProvisionUserCount
}

Add-LabMachineDefinition -Name BBCM01 -Roles $CMRole -PostInstallationActivity $CM1PostInstallJobs
```

## Deployment Details
The script does the following tasks
- Imports all AD computer accounts (excluding those generated by AutomatedBadLab) into the "All ABL Devices" device collection
- Enables the AD User Discovery and adds a random selection of 20 users to the "Selected Users" user collection
- Downloads and creates the Notepad++ and 7-Zip applications
- Distributes and deploys both applications to the "All ABL Devices" collection
